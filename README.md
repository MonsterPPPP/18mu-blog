# 18mu-blog

Markdown-first personal knowledge site, deployed through Cloudflare Workers Static Assets.

Production: https://18mu-blog.15589866906.workers.dev

## Commands

```powershell
npm install
npm run dev
npm run validate
npm run validate:relations
npm run build
npm run deploy
```
