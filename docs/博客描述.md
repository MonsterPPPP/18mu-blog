# 18mu-blog 内容架构说明

## 定位

这是一个优先服务于本人长期使用的公开个人网站：包含完成写作的中文博客 / 知识库、项目与经历的中英双语展示，以及公开、脱敏、可复用的 For Agent 内容。网站不提供登录、评论或付费内容。

Markdown 是唯一人工维护的内容源。页面、索引、标签、检索和部署都应自动化。

## 信息架构

- 首页：个人描述与博客、项目、经历、For Agent 的核心缩略。
- 博客 / 知识库：中文定稿文章、分类、标签、检索、认知地图与随机漫步。
- 项目与经历：中英双语，彼此双向关联，可单向跳转至博客或 For Agent。
- For Agent：公开、脱敏、与具体项目抽离的经验、踩坑记录和 Skills，拥有独立检索与标签。

## 认知功能

- flomo 认知地图：https://help.flomoapp.com/advance/cognitive-map.html
- flomo 随机漫步：https://help.flomoapp.com/advance/random-walk.html

博客文章基于语义相似度自动形成主题山峰，不以人工标签取代语义关系。地图展示所有已发布博客文章构成的当前整体，不提供时间轴、回放或历史切片。随机漫步默认随机选择起点，也支持从当前文章开始；不进入项目、经历或 For Agent 内容。

embedding 服务由维护者后续自行选择。模型端点、模型标识与密钥只配置在 Cloudflare Worker 中，绝不写入仓库或浏览器。
