# 18mu-blog 系统架构

本文记录当前已经实现并部署的系统。产品与内容边界以 `docs/博客描述.md` 为准，长期技术选择以 `docs/技术选型.md` 为准。

## 系统总览

```text
Markdown / 图片
  -> Content Collections + 关系校验
  -> Astro 静态构建 (.deploy/)
  -> Cloudflare Worker Static Assets

已发布博客 Markdown
  -> GitHub Actions 同步脚本
  -> Worker 的受保护同步 API
  -> 外部 embedding 服务
  -> Cloudflare KV 知识快照
  -> /api/knowledge
  -> 认知地图 / 随机漫步 React Islands
```

## 组件职责

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 内容源 | `src/content/` | 唯一人工维护的公开内容来源。 |
| 内容契约 | `src/content.config.ts` | 定义 Markdown frontmatter schema。 |
| 关系校验 | `scripts/validate-content-relations.mjs` | 校验关联 slug 指向存在且公开的记录。 |
| 静态站点 | Astro + TypeScript | 生成页面、RSS、sitemap 与详情路由。 |
| 交互 | React + D3 | 博客/Agent 搜索、认知地图、随机漫步。 |
| 边缘服务 | `worker.ts` | 静态资源、公开快照 API、受保护同步 API。 |
| 派生存储 | Cloudflare KV `KNOWLEDGE_KV` | 保存语义节点和邻居快照。 |
| 自动发布 | `.github/workflows/deploy.yml` | 构建、部署和知识同步。 |

## 内容集合与边界

| 集合 | 目录 | 路由 | 规则 |
| --- | --- | --- | --- |
| 博客 | `src/content/blog/` | `/blog/<slug>` | 中文定稿；仅 `published: true` 进入语义图谱。 |
| 项目 | `src/content/projects/` | `/projects/<slug>` | 中英双语；可关联经历、博客、For Agent。 |
| 经历 | `src/content/resume/` | `/resume` | 中英双语标准化经历全集。 |
| For Agent | `src/content/agent/` | `/agent/<slug>` | 公开、脱敏、可复用；独立搜索和标签，不进入图谱。 |

文件名去掉 `.md` 后是稳定 slug。项目可声明 `relatedResume`、`relatedBlog`、`relatedAgent`；经历可声明 `relatedProjects`。项目与经历在页面上自动双向链接，博客和 Agent 只是单向阅读链接，绝不参与 embedding 计算。

## 路由

- `/`：五个核心入口。
- `/blog`、`/blog/<slug>`、`/blog/category/<category>`、`/blog/tag/<tag>`：博客/知识库。
- `/projects`、`/projects/<slug>`：项目。
- `/resume`：经历。
- `/agent`、`/agent/<slug>`、`/agent/tag/<tag>`：For Agent。
- `/map`、`/walk`：仅使用公开语义快照。
- `/rss.xml`、`/sitemap-index.xml`、`/robots.txt`：公开索引产物。

`.deploy/` 是构建产物，不能提交。

## 语义同步和 API

`scripts/sync-knowledge.mjs` 只读取已发布博客，将 slug、标题、摘要、分类、标签、更新时间、URL 与正文发送到 Worker。Worker 调用外部 embedding 服务，计算余弦相似度、聚类与每篇文章至多 6 个邻居，并将派生快照写入 KV 的 `current` 键。

| API | 权限 | 行为 |
| --- | --- | --- |
| `GET /api/knowledge` | 公开 | 返回无密钥快照；不存在时返回空状态。 |
| `POST /api/sync/knowledge` | `Bearer SYNC_TOKEN` | 重建快照；仅 GitHub Actions 使用。 |
| 其他 `/api/*` | 公开 | 返回 `404` JSON。 |

浏览器永远不接触模型端点、API key、同步 token 或原始向量。

## 运行时与发布

`wrangler.toml` 定义 Worker `18mu-blog`、`.deploy/` 静态资源、KV binding 和公开模型参数。以下仅在 Cloudflare Worker Secret 中存在：`DASHSCOPE_API_KEY`、`SYNC_TOKEN`。

正常发布链路：

```text
git push origin main
  -> npm ci
  -> npm run build
  -> npx wrangler deploy
  -> npm run sync:knowledge
```

GitHub Actions 需要 `CLOUDFLARE_ACCOUNT_ID`、`CLOUDFLARE_API_TOKEN`、`KNOWLEDGE_SYNC_TOKEN`。`npm run deploy` 可供本机紧急发布，但不执行知识同步；之后仍需手动运行 GitHub 工作流。

生产地址：`https://18mu-blog.15589866906.workers.dev`。

## 接手时的实时核对

不要将本文视作运行状态证据。每次接手执行：

```powershell
git status --short --branch
npm run validate
npx wrangler whoami
npx wrangler secret list
npx wrangler kv namespace list
& 'C:\Program Files\GitHub CLI\gh.exe' run list --repo MonsterPPPP/18mu-blog --limit 5
```

健康发布的证据是：构建成功、GitHub Actions 部署成功、同一运行的 `sync:knowledge` 输出 `articleCount`、`/api/knowledge` 返回公开快照。

## 架构修改规则

- 变更内容字段时，同时更新 schema、模板、手册、Agent 协议和关系校验。
- 变更 Worker、KV、API、Secret 名称、工作流或模型提供方时，同时更新本文、配置手册和踩坑记录。
- 不引入 CMS、登录、评论、支付、浏览器端凭据，或把非博客内容放进语义图谱，除非先修改产品需求。
