# 18mu-blog 技术选型

- 框架：Astro + TypeScript，使用 Content Collections 校验 Markdown 内容。
- 样式：自定义 CSS 视觉系统；未来复杂交互使用 React Islands。
- 图谱：D3.js，待 embedding 服务配置后实现认知地图与随机漫步。
- 部署：Cloudflare Workers Static Assets，静态产物来自 `dist/`；`/api/` 预留给受保护的语义同步端点。
- 自动发布：GitHub Actions 在 `main` 上运行校验、构建和 Wrangler 部署。

Workers Static Assets 保持正文与索引静态化，同时允许后续添加 KV、同步 API 或边缘缓存而不迁移站点。本站不使用 CMS、登录、评论、数据库写作或 OpenAI/Workers AI 的固定绑定。

未来的语义同步由 GitHub Actions 将已发布博客内容发送至受保护 Worker 端点；Worker 调用可替换的 embedding 提供方，生成可重建的向量、聚类、地图和漫步快照。公开浏览器只读取无密钥的派生数据。
