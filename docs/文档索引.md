# 18mu-blog 文档索引

## 快速入口

## 维护本索引的规则

1. 新增长期文档时，同一提交把它加入本索引和 README。
2. 移动或改名文档时，同一提交更新仓库内链接，并用 `rg` 查找旧路径。
3. 本索引只指向权威文档，不复制正文；冲突时以可执行配置、schema 或工作流为准，并修正文档。
4. 不在本索引或链接目标中写入 Secret、API key、同步令牌或私人信息。
